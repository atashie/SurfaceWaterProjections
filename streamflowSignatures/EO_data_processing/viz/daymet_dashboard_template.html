How these numbers were made

Fresh: the Daymet V4 R1 North America daily mosaics for __YEAR__ (each file's SHA-256 matches NASA CMR's), polygons reprojected to the Daymet Lambert Conformal Conic grid without resampling it, weights = exactextract coverage × true cell area, and the daily basin value = the weighted mean of the cells that are valid that day.

Original: the co-author basin series (gdptools), daymet_1980_2023_rebuilt_10aug2026.parquet. It returned NaN for any basin touching a single fill cell.

Polygons: full resolution uses the unsimplified source polygons, as the 1980–2025 reprocess does; published uses the 200 m-simplified HydroShare Resource 4 layer.

Metrics: daily R² = 1 − SSE/SST about the 1:1 line over the 365 days; Δ = fresh − original. The map's colour range is ± the 99th percentile of |Δ| for the current view.
